## Billing and your subscription

Admins manage the subscription in **Settings → Billing**: **Manage billing** opens the Stripe portal to change the card or cancel, and the page lists past invoices to download. See [Plans and billing](/knowledge-base/workspace/plans-and-billing).

## Report abuse

Found a shared drawing or public link that breaks the rules? Report it at [sketa.app/abuse](https://sketa.app/abuse) with the link.

## Problems with these docs

Spotted a mistake or something missing? Open an issue or a pull request on [GitHub](https://github.com/sketa-labs/sketa-docs).

## How to ask for help effectively

Follow this order: **Goal → Environment → Changes → Results**.

- **Goal:** what you were trying to do. *I want to export my slides as PPTX.*
- **Environment:** browser and OS, and whether you were signed in. *Chrome on macOS, in a Plus workspace.*
- **Changes:** what changed before it broke. *It worked until I renamed the frames.*
- **Results:** what happened and what you expected. Include the exact error message, the HTTP status for API calls (`402 Sketa Plus required.`) or a screenshot.

Never share API keys or OAuth tokens in public channels.
