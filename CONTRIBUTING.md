# Contribute to the documentation

Thanks for helping improve the Sketa docs. This repository holds the documentation site only; the Sketa app itself is not open source.

## How to contribute

### Option 1: Edit directly on GitHub

1. Navigate to the page you want to edit.
2. Click the "Edit this file" button (the pencil icon).
3. Make your changes and submit a pull request.

### Option 2: Local development

1. Fork and clone this repository.
2. Create a branch for your changes.
3. Make your changes.
4. Run `npx mint dev` at the root and preview at `http://localhost:3000`.
5. Run `npx mint broken-links` to check links.
6. Commit your changes and submit a pull request.

For more details, see `README.md`. Found a problem but don't want to fix it yourself? Open an issue.

## Writing guidelines

- **Use active voice**: "Click **Share**" not "**Share** should be clicked".
- **Address the reader directly**: use "you" instead of "the user".
- **Keep sentences concise**: one idea per sentence.
- **Lead with the goal**: start instructions with what the reader wants to do.
- **Use the app's labels**: write button and menu names in bold, exactly as they appear in Sketa.
- **Use consistent terminology**: scene, collection, workspace, member, guest, frame, slide.
- **Include examples**: show, don't just tell.
- **Describe what exists today**: no screenshots of other products and no features that are not live.
