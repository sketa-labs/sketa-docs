[OpenAI Codex](https://github.com/openai/codex) is OpenAI's CLI agent for software development. You can connect it to Sketa's MCP server to draw and organize your boards with natural language.

## Prerequisites

- Codex CLI installed (`npm install -g @openai/codex`)
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Open the configuration file">
    Edit `~/.codex/config.toml` and add the Sketa server:

    ```toml
    [mcp_servers.sketa]
    url = "https://sketa.app/mcp"
    ```

    No `Authorization` header — Codex discovers OAuth from the URL. Or add it in one line: `codex mcp add sketa --url https://sketa.app/mcp`.
  </Step>
  <Step title="Sign in via codex mcp login">
    Run the OAuth flow so Codex caches the token:

    ```bash
    codex mcp login sketa
    ```

    Codex opens your browser to Sketa. Sign in, pick the **Workspace** this connection may use and click **Allow**, then return to the terminal. To use another workspace, connect again and pick it.
  </Step>
  <Step title="Verify the connection">
    Start Codex and ask:

    ```
    List my Sketa boards
    ```
  </Step>
</Steps>

<Tip>
  Codex uses TOML for configuration (not JSON). For sandboxed environments where the default callback port isn't reachable, set `mcp_oauth_callback_port` or `mcp_oauth_callback_url` in `config.toml`.
</Tip>
## Example prompts

```
Draw the architecture of a web app with a load balancer, two API servers and a database in a new board
```

```
Find the "Payments" box in my "Checkout flow" board and add a fraud-check step after it
```

```
Turn these notes into a four-slide deck with speaker notes, then screenshot each slide
```

```
Which boards did I edit this week?
```
