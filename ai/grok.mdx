[Grok](https://grok.com) is xAI's assistant. Add Sketa as a [custom MCP connector](https://docs.x.ai/grok/connectors) and Grok can draw diagrams and slides in your Sketa workspace from a normal Grok chat — on the web, iOS, or Android.

This page is for **Grok chat connectors**. It is not the [Grok Build CLI](https://docs.x.ai/build/features/mcp-servers) (`grok mcp add`) and not the [xAI API Remote MCP](https://docs.x.ai/developers/tools/remote-mcp) tools. Those are separate products.

<Note>
  Sketa is not in Grok's built-in or catalog connectors. You add it yourself: **New Connector → Custom**, then paste the Sketa MCP URL.
</Note>

## Prerequisites

- A [Grok](https://grok.com) account. [xAI documents connectors as available to all Grok users](https://docs.x.ai/grok/connectors).
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))
- On **Grok Business or Enterprise**, a team admin must provision the connector first — see [Grok Business and Enterprise](#grok-business-and-enterprise)

## Server URL

Use this exact URL. Do not add a trailing slash. Do not paste an OAuth authorize URL.

```
https://sketa.app/mcp
```

## Setup

<Steps>
  <Step title="Open Connectors">
    On the web, go to **[grok.com/connectors](https://grok.com/connectors)**.

    You can also start from a chat: click **+** → **Connectors** → **+ Add connector**.

    On iOS and Android, open **Settings → Connectors**.
  </Step>
  <Step title="Add a custom connector">
    Click **New Connector**, then select **Custom**.

    Paste the MCP server URL:

    ```
    https://sketa.app/mcp
    ```

    Name it `Sketa` if Grok asks for a name.

    If Grok shows OAuth client fields (Client ID, Client Secret, authorize/token URLs), leave them empty. Sketa uses OAuth 2.1 with Dynamic Client Registration. Grok discovers the endpoints from the MCP URL and registers itself.
  </Step>
  <Step title="Sign in to Sketa">
    Grok then asks you to authenticate. Complete the browser sign-in.

    1. Sign in to your Sketa account
    2. Review the permissions
    3. Pick the **Workspace** this connection may use and click **Allow** (to use another workspace, connect again and pick it)

    After that, Grok discovers the Sketa tools and makes them available in conversations — the same way it uses built-in and catalog connectors. You do not need to paste an API key.
  </Step>
  <Step title="Ask Grok to use Sketa">
    Open a new chat and ask in plain language. For example:

    ```
    List my Sketa scenes
    ```

    Grok should call Sketa tools instead of guessing. If it answers without tools, say you want it to use the **Sketa** connector.

    See the [Tools reference](/ai/tools-reference) for every tool and the recommended drawing workflow.
  </Step>
</Steps>

## Authentication

Use **OAuth**: a browser sign-in that binds the connection to one Plus workspace you pick. Leave OAuth client ID and secret empty: Sketa supports Dynamic Client Registration.

Sketa's MCP server also accepts an [API key](/knowledge-base/developers/api-keys) sent as an `Authorization: Bearer sketa_...` header, if you prefer a key to a browser sign-in. A key carries only its abilities, and a workspace key sees shared collections only.

To disconnect, remove the server from Grok. Leaving the workspace also ends the connection.

## What you can do

Once the connector is authorized, Grok can:

| Task | Examples |
|------|----------|
| **Drawing** | Draw diagrams with automatic layout; add shapes, arrows, sticky notes and images; search and edit scenes; take screenshots to check the result |
| **Slides** | Add slides, write speaker notes, reorder and hide slides |
| **Scenes and collections** | List, search, create, rename, move, pin and delete |
| **Workspace** | Read the workspace; manage members, invites and teams; read the audit log |

Members, invites, teams and the audit log need an admin. See [Permissions](/ai/introduction#permissions).

## Grok Business and Enterprise

On these plans, members cannot add a custom connector until a team admin provisions it.

<Accordion title="Admin: provision Sketa for the team">
  1. Sign in to [console.x.ai](https://console.x.ai), select your team, and open **Grok Business → Connectors**
  2. Click **+ Add Connector** → **Other**
  3. Paste `https://sketa.app/mcp`
  4. Finish the Sketa sign-in if Grok asks

  Adding and removing connectors requires **Team Read-Write** permissions. xAI's [connector management](https://docs.x.ai/grok/connector-management) page has the full admin flow.

  After the admin adds it, each member still opens **[grok.com/connectors](https://grok.com/connectors)** and signs in to **their own** Sketa account. The admin step only makes the connector available; it does not share one Sketa login across the team.
</Accordion>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Grok never asks me to sign in to Sketa">
    You may have pasted the wrong URL. Use `https://sketa.app/mcp` — not `/oauth/authorize`, not `/api`, and not a trailing slash. Remove the connector and add it again, then allow pop-ups so the OAuth window can open.
  </Accordion>
  <Accordion title="The connector is added but Grok does not call Sketa tools">
    Finish OAuth. Grok can list a custom server before you have authorized it. Open **[grok.com/connectors](https://grok.com/connectors)**, connect Sketa, then pick the workspace and click **Allow** on the Sketa screen. Then start a **new** chat and ask it to use the Sketa connector.
  </Accordion>
  <Accordion title="Grok says it cannot reach the server">
    Check the URL is exactly `https://sketa.app/mcp`, then remove the connector and add it again.
  </Accordion>
  <Accordion title="HTTP 402 — Sketa Plus required">
    The connection works, but the workspace it is bound to does not have Sketa Plus. Subscribe in **Settings → Billing**, or reconnect and pick a Plus workspace. See [Introduction](/ai/introduction#troubleshooting).
  </Accordion>
  <Accordion title="HTTP 401 or I need to sign in again">
    The OAuth session expired or was revoked. Open the connector and complete sign-in again.
  </Accordion>
  <Accordion title="A tool says “Not found.”">
    The resource is outside the workspace the connection is bound to, or you cannot see it (another member's private collection; a team-restricted collection for a workspace key). Ask the assistant to list scenes or collections first instead of guessing ids.
  </Accordion>
  <Accordion title="Custom is missing, or I cannot add a connector">
    On Grok Business / Enterprise, only an admin can provision custom MCP. Ask someone with **Team Read-Write** to add Sketa in [console.x.ai](https://console.x.ai) first. On personal Grok, open **[grok.com/connectors](https://grok.com/connectors)** and choose **Custom**, not a catalog app.
  </Accordion>
</AccordionGroup>
