[Gemini CLI](https://github.com/google-gemini/gemini-cli) is Google's command-line AI assistant. You can connect it to Sketa's MCP server to draw and organize your boards with natural language.

## Prerequisites

- Gemini CLI installed
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Open the settings file">
    Edit your Gemini CLI settings at `~/.gemini/settings.json`:

    ```json
    {
      "mcpServers": {
        "sketa": {
          "httpUrl": "https://sketa.app/mcp",
          "oauth": {
            "enabled": true
          }
        }
      }
    }
    ```

    With `oauth.enabled`, Gemini CLI discovers Sketa's OAuth metadata from the URL and registers dynamically. For project-level configuration, create `.gemini/settings.json` in your project root instead.
  </Step>
  <Step title="Restart Gemini CLI and sign in">
    Close and reopen Gemini CLI. The first Sketa call prompts you to sign in — Gemini CLI prints the authorize URL or opens your browser. Sign in, pick the **Workspace** this connection may use and click **Allow**, then return to the terminal. To use another workspace, connect again and pick it.
  </Step>
  <Step title="Verify the connection">
    Ask Gemini to interact with your Sketa account:

    ```
    List my Sketa boards
    ```
  </Step>
</Steps>

<Tip>
  Gemini CLI uses `"httpUrl"` for HTTP-streaming servers (not `"url"`). The `"url"` field is used for SSE transport only.
</Tip>
## Example prompts

```
Draw the architecture of a web app with a load balancer, two API servers and a database in a new board
```

```
Find the "Payments" box in my "Checkout flow" board and add a fraud-check step after it
```

```
Turn these notes into a four-slide deck with speaker notes, then screenshot each slide
```

```
Which boards did I edit this week?
```
