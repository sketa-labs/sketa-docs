[OpenClaw](https://openclaw.ai) is an open-source personal AI assistant that runs on your machine and talks across chat channels. You can connect it to Sketa's MCP server so the agent can draw and organize your scenes with natural language.

## Prerequisites

- OpenClaw installed ([getting started](https://docs.openclaw.ai/start/getting-started))
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Add the Sketa MCP server">
    Register the remote server with OAuth (Streamable HTTP):

    ```bash
    openclaw mcp add sketa \
      --url https://sketa.app/mcp \
      --transport streamable-http \
      --auth oauth \
      --oauth-scope mcp:use
    ```

    This saves the definition under `mcp.servers` in `~/.openclaw/openclaw.json`. It does not connect or log in yet.
  </Step>
  <Step title="Sign in with OAuth">
    Start the login flow:

    ```bash
    openclaw mcp login sketa
    ```

    OpenClaw prints an authorization URL and stores a temporary PKCE verifier. Open the URL in a browser, sign in to Sketa, pick the **Workspace** this connection may use and click **Allow** (to use another workspace, connect again and pick it). After approval, pass the returned code back:

    ```bash
    openclaw mcp login sketa --code YOUR_CODE
    ```
  </Step>
  <Step title="Reload and verify">
    Active agent or Gateway processes may still hold a stale tool list. Reload MCP clients in this CLI process (or restart the Gateway / **Save & Publish** from the Control UI), then probe:

    ```bash
    openclaw mcp reload
    openclaw mcp doctor sketa --probe
    ```

    Or:

    ```bash
    openclaw mcp probe sketa
    ```

    Then ask your OpenClaw agent (Control UI, Telegram, Discord, etc.):

    ```
    List my Sketa scenes
    ```
  </Step>
</Steps>

<Tip>
  Manage servers in the Control UI at **Settings → MCP** (`openclaw dashboard`, path `/settings/mcp`). Use `openclaw mcp logout sketa` to clear stored OAuth credentials without removing the server definition. If `openclaw mcp status --verbose` reports `authorization-required`, run `openclaw mcp login sketa` again.
</Tip>

## Manual configuration

Equivalent config written by `openclaw mcp add`:

```json5
{
  mcp: {
    servers: {
      sketa: {
        url: "https://sketa.app/mcp",
        transport: "streamable-http",
        auth: "oauth",
        oauth: {
          scope: "mcp:use",
        },
      },
    },
  },
}
```

Save in `~/.openclaw/openclaw.json`, then run `openclaw mcp login sketa` and complete the `--code` step.
