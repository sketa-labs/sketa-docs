[Perplexity](https://www.perplexity.ai) supports custom remote MCP connectors on paid plans, so you can connect Sketa and draw and organize your scenes from Perplexity chat and [Computer](https://www.perplexity.ai/changelog/what-we-shipped---march-13-2026) workflows.

<Note>
  This guide connects **Sketa into Perplexity** as a custom remote connector. Perplexity also ships its own search MCP for use *inside* other clients (Claude, Cursor, etc.) — that is a different product: [Perplexity MCP Server](https://docs.perplexity.ai/docs/getting-started/integrations/mcp-server).
</Note>

## Prerequisites

- A Perplexity **Pro, Max, or Enterprise** account ([custom remote connectors](https://www.perplexity.ai/help-center/en/articles/13915507-adding-custom-remote-connectors) are not available on Free)
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Open Connectors">
    In Perplexity, open **Account Settings → Connectors**. From **Computer**, you can also open **Connectors** in the left sidebar. Click **+ Custom connector**.
  </Step>
  <Step title="Add a remote connector">
    Choose **Remote** and fill in:

    | Field | Value |
    |-------|-------|
    | **Name** | `Sketa` |
    | **MCP Server URL** | `https://sketa.app/mcp` |
    | **Authentication** | **OAuth 2.0** (leave Client ID / Secret empty — Sketa uses Dynamic Client Registration) |
    | **Transport** | Streamable HTTP if offered (prefer over SSE; often auto-detected) |

    Acknowledge the risk notice for custom connectors, then click **Add**.
  </Step>
  <Step title="Authorize Sketa">
    Open the new connector card and complete OAuth. Sign in to Sketa, pick the **Workspace** this connection may use and click **Allow**. To use another workspace, connect again and pick it. The connector should show as connected with Sketa tools available.
  </Step>
  <Step title="Use Sketa in a thread">
    Start a new conversation or Computer task, enable the **Sketa** connector for that thread if it is not already on, and ask:

    ```
    List my Sketa scenes
    ```

    Perplexity will call the Sketa tools to list your scenes.
  </Step>
</Steps>

<Note>
  Perplexity reaches the MCP server from its cloud over HTTPS. The hosted endpoint `https://sketa.app/mcp` works out of the box.
</Note>

<Warning>
  Choose **OAuth 2.0** for the connector. If you prefer an API key, use an auth mode that sends it as an `Authorization: Bearer sketa_...` header; see [API keys](/knowledge-base/developers/api-keys).
</Warning>

<Accordion title="Enterprise / organization connectors">
  On Enterprise, admins can share connectors organization-wide and control whether members may add their own. Members still authenticate individually for OAuth connectors unless your admin configures organization-wide auth.
</Accordion>

## Example prompts

```
Draw the architecture of a web app with a load balancer, two API servers and a database in a new scene
```

```
Find the "Payments" box in my "Checkout flow" scene and add a fraud-check step after it
```

```
Turn these notes into a four-slide deck with speaker notes, then screenshot each slide
```

```
Which scenes did I edit this week?
```
