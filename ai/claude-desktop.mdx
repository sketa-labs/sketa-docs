[Claude Desktop](https://claude.ai/download) is Anthropic's desktop application for chatting with Claude. You can connect it to Sketa's MCP server to draw and organize your boards through conversation.

## Prerequisites

- Claude Desktop installed
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Open the Connectors settings">
    In Claude Desktop, go to **Settings** → **Connectors** and click **Add custom connector**.
  </Step>
  <Step title="Add the Sketa server URL">
    Paste the server URL:

    ```
    https://sketa.app/mcp
    ```

    Leave the **Advanced settings** (Client ID / Client Secret) empty — Sketa supports Dynamic Client Registration, so Claude Desktop registers itself automatically.
  </Step>
  <Step title="Sign in through your browser">
    Claude Desktop opens a browser window to Sketa asking you to sign in. Pick the **Workspace** this connection may use and click **Allow**, then return to Claude Desktop — the connector flips to **Connected**. To use another workspace, connect again and pick it.
  </Step>
  <Step title="Verify the connection">
    Start a new conversation and ask Claude to interact with your Sketa account:

    ```
    List my Sketa boards
    ```

    Claude will use the Sketa tools to list your boards.
  </Step>
</Steps>

<Note>
  Claude Desktop's connector runs from Anthropic's cloud, not from your machine, so the MCP server has to be reachable over the public internet. The hosted endpoint `https://sketa.app/mcp` is.
</Note>
