[Antigravity](https://antigravity.google) is Google's AI coding agent. You can connect it to Sketa's MCP server when the client can complete OAuth.

## Prerequisites

- Antigravity installed
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Open the MCP configuration file">
    From Antigravity, open **MCP Servers → Manage → View raw config**, then add the Sketa server **without** an `Authorization` header so OAuth can run:

    ```json
    {
      "mcpServers": {
        "sketa": {
          "serverUrl": "https://sketa.app/mcp"
        }
      }
    }
    ```
  </Step>
  <Step title="Sign in through your browser">
    Restart Antigravity if needed, then trigger a Sketa tool call. Complete the browser OAuth flow: pick the **Workspace** this connection may use and click **Allow**. To use another workspace, connect again and pick it.
  </Step>
  <Step title="Verify the connection">
    Ask Antigravity:

    ```
    List my Sketa collections
    ```
  </Step>
</Steps>

<Tip>
  Antigravity uses `"serverUrl"` for remote MCP connections (not `"url"`). This is the same format used by Devin Desktop's Cascade agent.
</Tip>

<Note>
  If Antigravity cannot finish OAuth (no browser callback), add an `Authorization: Bearer sketa_...` header with an [API key](/knowledge-base/developers/api-keys) to the server config instead.
</Note>
