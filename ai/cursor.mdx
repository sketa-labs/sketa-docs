[Cursor](https://cursor.com) is an AI-powered code editor. You can connect it to Sketa's MCP server to draw and organize your scenes directly from the editor.

## Prerequisites

- Cursor 1.0 or later (earlier versions don't support OAuth for remote MCP servers)
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Create the MCP configuration file">
    In your project root, create or edit `.cursor/mcp.json`:

    ```json
    {
      "mcpServers": {
        "sketa": {
          "url": "https://sketa.app/mcp"
        }
      }
    }
    ```

    No `Authorization` header is needed — Cursor detects OAuth from the URL and registers itself dynamically.
  </Step>
  <Step title="Sign in through your browser">
    Open Cursor's MCP settings (or the AI chat) and click **Connect** next to **sketa**. Cursor opens a browser window for the Sketa sign-in. Sign in, pick the **Workspace** this connection may use and click **Allow**, then return to Cursor. To use another workspace, connect again and pick it.
  </Step>
  <Step title="Verify the connection">
    Open the AI chat panel and ask:

    ```
    List my Sketa collections
    ```
  </Step>
</Steps>
