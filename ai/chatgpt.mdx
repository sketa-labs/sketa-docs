[ChatGPT](https://chatgpt.com) can connect to Sketa's MCP server as a developer-mode app, so you can draw and organize scenes with natural language in chat.

## Prerequisites

- A ChatGPT **Pro, Plus, Business, Enterprise, or Education** account on the **web** ([Developer mode](https://developers.openai.com/api/docs/guides/developer-mode) — not available on Free; not guaranteed on mobile)
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Enable Developer mode">
    In ChatGPT on the web, open **Settings → Security and login** and turn on **Developer mode**.

    If that toggle is missing, try **Settings → Apps → Advanced settings**. On Business / Enterprise / Education workspaces, an admin may need to allow Developer mode first.
  </Step>
  <Step title="Create a developer-mode app">
    With Developer mode on, open the connectors flow (or go directly to [chatgpt.com/plugins#settings/Connectors?create-connector=true&redirectAfter=%2Fplugins](https://chatgpt.com/plugins#settings/Connectors?create-connector=true&redirectAfter=%2Fplugins)). You can also use **Settings → Plugins** / **Settings → Apps** and click **+**.

    Fill in:

    | Field | Value |
    |-------|-------|
    | **Name** | `Sketa` |
    | **Description** | `Draw diagrams and slides in Sketa` |
    | **MCP server URL** | `https://sketa.app/mcp` |

    For authentication, use **OAuth**. Leave Client ID / Secret blank if shown — Sketa supports Dynamic Client Registration and discovers OAuth from the URL.
  </Step>
  <Step title="Authorize and review tools">
    Create the connection. ChatGPT may let you finish creating it without signing in; it then asks you to sign in inside the conversation the first time you use Sketa, and again whenever the sign-in expires. Complete the Sketa OAuth sign-in when prompted: pick the **Workspace** this connection may use and click **Allow**. To use another workspace, connect again and pick it. Open the app details page to review discovered tools; you can toggle tools on or off and **Refresh** later when the MCP server changes.
  </Step>
  <Step title="Use Sketa in a conversation">
    Start a new chat. From the composer **+** / Plus menu, choose **Developer mode**, enable the **Sketa** app for that conversation, and ask:

    ```
    List my Sketa scenes
    ```

    ChatGPT will call the Sketa tools to list your scenes.
  </Step>
</Steps>

<Note>
  ChatGPT only connects to remote HTTPS MCP servers (from OpenAI's infrastructure). The hosted endpoint `https://sketa.app/mcp` works out of the box. Local `stdio` MCP servers are not supported.
</Note>

<Note>
  Write actions (create, update, delete) require confirmation by default in Developer mode. Review each tool payload before approving. Tools annotated as read-only skip that confirmation.
</Note>

<Tip>
  After MCP server changes, open the app under **Settings → Plugins** (or **Apps**), click **Refresh**, and start a new conversation so ChatGPT picks up updated tools and descriptions.
</Tip>

## Example prompts

```
Draw the architecture of a web app with a load balancer, two API servers and a database in a new scene
```

```
Find the "Payments" box in my "Checkout flow" scene and add a fraud-check step after it
```

```
Turn these notes into a four-slide deck with speaker notes, then screenshot each slide
```

```
Which scenes did I edit this week?
```
