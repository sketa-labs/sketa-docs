[OpenCode](https://opencode.ai) is an open-source AI coding assistant that runs in your terminal. You can connect it to Sketa's MCP server to draw and organize your scenes with natural language.

## Prerequisites

- OpenCode installed
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Open the configuration file">
    Edit `opencode.json` in your project root (or `~/.config/opencode/opencode.json` for global config):

    ```json
    {
      "mcp": {
        "sketa": {
          "type": "remote",
          "url": "https://sketa.app/mcp",
          "enabled": true
        }
      }
    }
    ```

    No `Authorization` header — OpenCode discovers OAuth from the URL.
  </Step>
  <Step title="Sign in with `mcp auth`">
    Run the OAuth flow explicitly so OpenCode caches the token:

    ```bash
    opencode mcp auth sketa
    ```

    OpenCode opens your browser to Sketa. Sign in, pick the **Workspace** this connection may use and click **Allow**, then return to the terminal. To use another workspace, connect again and pick it.
  </Step>
  <Step title="Verify the connection">
    Inside OpenCode, ask:

    ```
    List my Sketa collections
    ```

    If anything looks off, `opencode mcp debug sketa` prints the current token state.
  </Step>
</Steps>

<Tip>
  OpenCode also supports `opencode mcp logout sketa` to revoke the cached token if you need to switch accounts.
</Tip>
## Example prompts

```
Draw the architecture of a web app with a load balancer, two API servers and a database in a new scene
```

```
Find the "Payments" box in my "Checkout flow" scene and add a fraud-check step after it
```

```
Turn these notes into a four-slide deck with speaker notes, then screenshot each slide
```

```
Which scenes did I edit this week?
```
