[Claude Code](https://code.claude.com/docs) is Anthropic's CLI tool for working with Claude directly in your terminal. You can connect it to Sketa's MCP server to draw and organize your scenes with natural language.

## Prerequisites

- Claude Code installed ([install guide](https://code.claude.com/docs/en/setup))
- A Sketa account in a Plus workspace ([plans and billing](/knowledge-base/workspace/plans-and-billing))

## Setup

<Steps>
  <Step title="Add the Sketa MCP server">
    Run the following command in your terminal:

    ```bash
    claude mcp add --transport http sketa https://sketa.app/mcp
    ```

    This adds the server for the current project, for you only (local scope). Use `--scope project` to share it through `.mcp.json`, or `--scope user` for every project.
  </Step>
  <Step title="Sign in through your browser">
    Start Claude Code and trigger the first Sketa call:

    ```bash
    claude
    ```

    ```
    List my Sketa scenes
    ```

    Claude Code opens a browser window asking you to sign in to Sketa and authorize the connection. Sign in, pick the **Workspace** this connection may use and click **Allow**. Claude Code stores the OAuth token and refreshes it automatically from then on. To use another workspace, connect again and pick it.
  </Step>
</Steps>

## Manual configuration

If you prefer to edit the config file directly, this is what `claude mcp add --scope project` writes to `.mcp.json` (no `Authorization` header — OAuth is discovered from the URL):

```json
{
  "mcpServers": {
    "sketa": {
      "type": "http",
      "url": "https://sketa.app/mcp"
    }
  }
}
```

Drop it in `.mcp.json` for project scope. With `--scope user` the same block goes under `mcpServers` in `~/.claude.json`.
