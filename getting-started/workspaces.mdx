## Accounts

Sign up at [sketa.app/register](https://sketa.app/register) with your name, e-mail and password, or with GitHub. There is no other sign-in method and no two-factor authentication.

## Workspaces

Everything you save (scenes, collections, library items, API keys) belongs to a **workspace**. A workspace is your team and the unit of billing.

- Every account gets a **personal workspace** at sign-up, on the Free plan. It holds 1 cloud scene and has no other members.
- Create more workspaces with **New workspace** in the workspace switcher in the sidebar, where you also switch between them. You can belong to as many as you like.
- Switch between them from the workspace switcher in the sidebar.
- A workspace has a name and an image (shown in the switcher), set in **Settings → Workspace → General**. Workspace settings always apply to the current workspace.

Upgrading a workspace to [Sketa Plus](/knowledge-base/workspace/plans-and-billing) unlocks unlimited scenes and collections, members, guests and every Plus feature for everyone in it.

## Members

Members belong to the workspace: they see its dashboard and shared collections, create scenes there and get Plus features and AI limits through it.

- **Each member is a paid seat.** Adding one raises the subscription's quantity; removing one lowers it.
- Members are invited by e-mail, one by one, with a role. The invite expires after 3 days.
- Only Plus workspaces can have members besides the owner.

See [Members and invites](/knowledge-base/workspace/members-and-invites).

## Roles

| | Owner | Admin | Member |
| --- | --- | --- | --- |
| Draw, create and organize scenes and collections | ✓ | ✓ | ✓ |
| Invite, remove and block members; change roles | ✓ | ✓ | |
| Billing, teams, audit log, workspace settings | ✓ | ✓ | |
| Create their own API keys and MCP connections (Plus) | ✓ | ✓ | ✓ |
| See and revoke every member's API keys and MCP connections | ✓ | ✓ | |
| Delete the workspace | ✓ | | |

The owner (who created the workspace) is always an admin and cannot be removed.

## Teams

Admins can group members into **teams** and restrict a shared collection to some teams: only their members and the admins see it. See [Teams](/knowledge-base/workspace/teams).

## Guests

A guest is someone outside the workspace who gets access to **one scene**. Guests are free: they never take a seat.

- Invite a guest from the scene's **Share** dialog, with **Can view**, **Can comment** or **Can edit**.
- Guests need a (free) Sketa account. Someone without one shows as **Pending sign-up** until they register with that e-mail.
- Guests find the scene under **Shared with me**. They do not see the workspace's collections or dashboard, and their AI credits count against their own plan, not the workspace's.
- Sharing with guests needs Sketa Plus.

Anyone who needs collections, the team dashboard or to create scenes in the workspace should become a member. See [Sharing and public links](/knowledge-base/scenes/sharing-and-public-links).
