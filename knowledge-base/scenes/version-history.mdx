<Note>
  Version history needs Sketa Plus.
</Note>

Open **Version history** from the editor's main menu. It lists the saved versions of the scene, newest first, with who edited and how many elements each has.

## When versions are saved

Sketa saves a version every few minutes while people edit (at most every 10 minutes), when the last person leaves the scene, and right before a restore.

## Preview and restore

Click a version to open a read-only preview. **Restore** brings the scene back to that version for everyone editing it. The current version is saved to the history first, so a restore can itself be undone by restoring the version before it.

Members who can edit the scene can restore. Guests and read-only workspaces can only preview.
