A **Code block** shows code on a dark card with syntax colors and the language name at its top-left corner. Add one with <kbd>`</kbd> (the backquote key), or from **More** in the [+ panel](/knowledge-base/editor/insert-panel).

## Write and edit

The code editor opens over the card as soon as the block is placed. Double-click a block, or press <kbd>Enter</kbd> with it selected, to edit it again.

- Type or paste your code: lines never wrap, so the card widens to fit.
- <kbd>Tab</kbd> indents.
- Pick the **Language** above the card.
- **Done**, <kbd>Escape</kbd> or <kbd>Ctrl</kbd> <kbd>Enter</kbd> (<kbd>⌘</kbd> <kbd>Enter</kbd> on macOS) saves. The whole edit is one step you can undo.

## Languages

**Plain text**, **Bash**, **C**, **C++**, **C#**, **CSS**, **Go**, **GraphQL**, **HTML**, **Java**, **JavaScript**, **JSON**, **Kotlin**, **Markdown**, **PHP**, **Python**, **Ruby**, **Rust**, **SQL**, **Swift**, **TypeScript** and **YAML**.

Code blocks export to PNG, SVG and PDF with their colors, and the [MCP server](/ai/introduction) can add them too.

<Tip>
  During a [voice conversation](/knowledge-base/boards/voice-and-spotlight), holding the backquote key talks while you are muted, so use the + panel to add a code block then.
</Tip>
