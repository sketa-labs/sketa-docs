Any text can carry formatting: free texts, labels inside shapes, sticky notes and table cells.

| Format | Shortcut | In the selection toolbar |
| --- | --- | --- |
| **Bold** | <kbd>Ctrl</kbd> <kbd>B</kbd> | **Bold** |
| **Strikethrough** | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>X</kbd> | **Strikethrough** |
| **Bulleted list** | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>8</kbd> | **Bulleted list** |
| **Link** | <kbd>Ctrl</kbd> <kbd>K</kbd> while typing | **Link** |

On macOS, use <kbd>⌘</kbd> instead of <kbd>Ctrl</kbd>.

## While typing or on the whole text

- **While you type**, a format applies to the selected words, or to what you type next. A bulleted list applies to the selected lines.
- **With elements selected** (not typing), the same keys and buttons format their whole text: select three sticky notes and press <kbd>Ctrl</kbd> <kbd>B</kbd> to make all three bold.

Press the same key again to remove the format.

## Links

A link takes a web address (`http` or `https`) or an e-mail address (`mailto:`); anything else is refused. To open a linked word on the canvas, <kbd>Ctrl</kbd> + click it (<kbd>⌘</kbd> + click on macOS); in **View mode** a plain click opens it. Outside text, <kbd>Ctrl</kbd> <kbd>K</kbd> is **Edit link**, a link on the whole element.

## Bulleted lists

Each line of the list gets a bullet and a hanging indent, so wrapped lines stay aligned.

## What stays plain

Formatting only changes how the text looks. Search (**Find on canvas**), the API, the MCP server and AI always read the plain text.
