## Actions

**Actions** (<kbd>Ctrl</kbd> <kbd>K</kbd>, <kbd>⌘</kbd> <kbd>K</kbd> on macOS, or the toolbar button next to **+**) runs any command or tool by name. Type to search, then press <kbd>Enter</kbd>.

With nothing typed it shows:

- **Tools**: the tools that are not in the toolbar, like **Insert image**, **Web embed**, **Laser pointer**, **Lasso selection**, **Paint bucket**, **Draw to shape** and **AI diagram**. The Actions button shows the tool you picked here while it is active.
- **Recents**: what you ran from the palette lately.
- **Common settings**: switches such as **Keep tool selected**, snapping, the grid, **Minimize UI** and **View mode**.

<kbd>Ctrl</kbd> <kbd>/</kbd> and <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>P</kbd> open it too.

## The main menu

The menu behind the logo, top left, follows FigJam's: **Back to dashboard**, **Actions…**, then:

| Menu | Holds |
| --- | --- |
| **File** | Open, save and export the board |
| **Edit** | Undo and redo, copy and paste (**Paste over selection**, **Paste to replace**), **Find on canvas**, **Find next**, **Find previous**, **Find and replace**, **Select all**, **Select inverse**, copy as PNG, SVG or text, copy and paste styles |
| **View** | Dot grid, grid, snapping, **Minimize UI**, **Hide UI**, multiplayer cursors, view mode, stats, comments, zoom and pages |
| **Object** | Group, sections, layer order, flip and rotate, lock and **Unlock all**, links, library |
| **Text** | **Bold**, **Italic**, **Underline**, **Strikethrough**, links, lists and size |
| **Arrange** | Align, distribute and **Tidy up** |
| **Preferences** | Your editor preferences (below), theme and language |
| **Help and account** | Help, **AI balance** and your account |

## Preferences

| Preference | Does |
| --- | --- |
| **Snap to dot grid** | Elements snap to the dots while you move or draw them |
| **Keyboard zooms into selection** | Zoom keys zoom around the selection instead of the view's center |
| **Invert zoom** | Flips the scroll direction for zooming |
| **Ctrl+click opens the context menu** | For one-button mice and trackpads |
| **Shake cursor for high five** | See [high fives](/knowledge-base/editor/stamps-reactions-and-chat#high-five) |
| **Show templates for new files** | New boards open the [templates](/knowledge-base/editor/templates) gallery |
| **Scroll wheel zoom** | The wheel zooms instead of scrolling |
| **Right-click drag to pan** | Dragging with the right button moves the canvas |
| **Spell check** | Underlines misspelled words while you type |

Signed in, your preferences follow you to any browser; without an account they stay in this browser.

## Context menus

Right-click (or long-press on a touch screen) an element for FigJam's items first: copy, paste, **Paste to replace**, delete, copy link, **Copy as PNG**, export, layer order and lock. Sketa's extras follow, like **Move to page** when the scene has [pages](/knowledge-base/editor/pages), AI and sections. On the empty canvas: paste, **Unlock all**, cursor chat, hide UI, comments and **Actions**.

## The help menu

The **?** at the bottom right has the help center, **Release notes** (the [changelog](/changelog)), **Give feedback** ([feedback](/feedback)), **Report abuse**, the keyboard shortcuts (<kbd>?</kbd>) and the language.
