Select one or more elements and a dark bar appears above them: the **Selection toolbar**. It only shows the controls that apply to what you selected, hides while you drag, and steps aside while a drawing tool is active.

## Controls

| Control | What it does |
| --- | --- |
| **Shapes** | Turns the selected shapes into another shape (see [Shapes and quick connect](/knowledge-base/editor/shapes-and-quick-connect)). |
| **Color** | The stroke color, or for filled shapes the **Fill** with its **Filled**, **Transparent** and **No fill** modes, plus **Pattern** and **Opacity**. Sticky notes show **Sticky color** instead. |
| **Line** | **Stroke style** (solid, dashed, dotted, or no line for filled shapes), stroke color, **Stroke width**, **Sloppiness** and **Edges**. |
| **Arrow type** | **Sharp arrow**, **Curved arrow** or **Elbow arrow**, for arrows. |
| **Font** | The font of texts and labels; the button shows "Aa" in the current font. |
| **Size** | **Small**, **Medium**, **Large**, **Extra large**, **Huge** or a number. |
| **Bold**, **Italic**, **Underline**, **Strikethrough**, **Link**, lists | Format the text (see [Text formatting](/knowledge-base/editor/text-formatting)). |
| **Text align** | Horizontal and vertical alignment of texts and labels. |
| **AI** | **Summarize**, **Sort into sections** or **Rewrite** (see [AI](/knowledge-base/ai#summarize-sort-and-rewrite)). |
| **Section controls** | **Stroke**, **Rename**, **Hide contents**, **Lock**, **Resize to fit** and **Use as slide** (see [Sections](/knowledge-base/editor/sections)). |
| **Add text** | Starts a label inside the selected shape. |
| **Table actions** | Rows, columns, **Header row** and **Cell color** of a selected table (see [Tables](/knowledge-base/editor/tables)). |
| **Show author** | Shows or hides the author of the selected sticky notes. |
| **Align**, **Wrap in section** | Align, distribute or **Tidy up** several elements, or put the selection in a new section. |
| **More actions** | **Duplicate**, **Delete**, **Group**, **Ungroup**, **Lock**, **Edit link**, **Copy link to object** and the layer order. |

## Colors

The color popover shows two rows of colors: vivid colors on the first row, neutrals and the rest on the second. The last cell, a color wheel, opens the full picker with every palette hue, its **Shades**, a hex code field and the eyedropper (in browsers that support it). When the selection uses a color outside the two rows, that cell shows it.

Colors are plain values: a board keeps the exact color you picked. **Transparent** fills use the same color, made see-through.

## Style for new elements

With nothing selected, the bar above the toolbar shows **Style for new elements**: the color, line and text settings the next element you draw gets. The last style you used also becomes the default. The pens of the marker group have their own bar (see [Marker, highlighter and washi tape](/knowledge-base/editor/markers-and-tape)).

## On a phone

Phones keep the style sheet: select elements and open it from the bottom of the screen to reach the same settings in a larger layout.
