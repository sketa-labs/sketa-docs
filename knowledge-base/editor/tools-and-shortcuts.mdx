Sketa uses FigJam's keyboard shortcuts: if you know FigJam, your fingers already know Sketa. Where FigJam has no key for something Sketa does, Sketa keeps its own key when it is free; everything else is in [Actions](/knowledge-base/editor/actions-and-menus) (<kbd>Ctrl</kbd> <kbd>K</kbd>).

Press <kbd>?</kbd> in the editor for **Keyboard shortcuts**, the full list for macOS or Windows / Linux. On macOS, <kbd>Ctrl</kbd> below is <kbd>⌘</kbd> and <kbd>Alt</kbd> is <kbd>⌥</kbd>. Tool keys never fire while you type in a text, a sticky note or a field.

## Keys that moved

Sketa used to have its own keys. These changed to FigJam's: sticky note <kbd>S</kbd> (was <kbd>N</kbd>, still works), marker <kbd>M</kbd> (<kbd>X</kbd> is now the connector), stamp <kbd>E</kbd> (the eraser is <kbd>Shift</kbd> <kbd>Backspace</kbd>), washi tape <kbd>W</kbd>, section <kbd>Shift</kbd> <kbd>S</kbd>, **Actions** <kbd>Ctrl</kbd> <kbd>K</kbd>, link <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>U</kbd>, ungroup <kbd>Ctrl</kbd> <kbd>Backspace</kbd>, wrap in section <kbd>Ctrl</kbd> <kbd>S</kbd>, align with <kbd>Alt</kbd> + letter, and <kbd>Tab</kbd> selects the next element. **Switch shape type**, **Edit link**, **Paste as plain text** and **Snap to objects** no longer have keys (run them from **Actions** or the menus), and resetting the canvas is <kbd>Ctrl</kbd> <kbd>Delete</kbd> only.
