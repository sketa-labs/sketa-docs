Press <kbd>?</kbd> in the editor for **Keyboard shortcuts**, the full list for macOS or Windows / Linux. On macOS, <kbd>Ctrl</kbd> below is <kbd>⌘</kbd>.

## Tools

| Tool | Key |
| --- | --- |
| **Hand** | <kbd>H</kbd> |
| **Selection** | <kbd>V</kbd> or <kbd>1</kbd> |
| **Rectangle** | <kbd>R</kbd> or <kbd>2</kbd> |
| **Diamond** | <kbd>D</kbd> or <kbd>3</kbd> |
| **Ellipse** | <kbd>O</kbd> or <kbd>4</kbd> |
| **Arrow** | <kbd>A</kbd> or <kbd>5</kbd> |
| **Line** | <kbd>L</kbd> or <kbd>6</kbd> |
| **Marker** (freehand, pressure-sensitive) | <kbd>P</kbd>, <kbd>X</kbd> or <kbd>7</kbd> |
| **Highlighter** | <kbd>Shift</kbd> <kbd>M</kbd> |
| **Washi tape** | <kbd>U</kbd> |
| **Text** | <kbd>T</kbd> or <kbd>8</kbd> |
| **Insert image** | <kbd>9</kbd> |
| **Table** | In the toolbar |
| **Eraser** | <kbd>E</kbd> or <kbd>0</kbd> |
| **Frame** | <kbd>F</kbd> |
| **Sticky note** | <kbd>N</kbd> |
| **Laser pointer** (visible to everyone in a live session) | <kbd>K</kbd> |
| **Paint bucket** (fills a closed area) | <kbd>B</kbd> |
| **Stamp** | <kbd>M</kbd> |
| **Draw to shape** (turns a scribble into the shape it recognizes) | <kbd>Shift</kbd> <kbd>X</kbd> |
| **Keep selected tool active** | <kbd>Q</kbd> |

**Frame**, **Sticky note**, **Web embed**, **Laser pointer**, **Draw to shape**, **Paint bucket**, **Lasso selection**, **Text to diagram** and **Mermaid to diagram** are in the toolbar's **More tools** menu. The library shapes are in the toolbar's **Shapes** menu (see [Shapes and quick connect](/knowledge-base/editor/shapes-and-quick-connect)).

## Text

These work on the selected words while you type, and on the whole text of the selected elements otherwise. See [Text formatting](/knowledge-base/editor/text-formatting).

| Action | Shortcut |
| --- | --- |
| Bold | <kbd>Ctrl</kbd> <kbd>B</kbd> |
| Strikethrough | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>X</kbd> |
| Bulleted list | <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>8</kbd> |
| Link (while typing) | <kbd>Ctrl</kbd> <kbd>K</kbd> |
| Finish typing | <kbd>Escape</kbd> |

## Tables

While you type in a cell (see [Tables](/knowledge-base/editor/tables)):

| Action | Shortcut |
| --- | --- |
| Next cell (a new row after the last one) | <kbd>Tab</kbd> |
| Previous cell | <kbd>Shift</kbd> <kbd>Tab</kbd> |
| Cell below | <kbd>Enter</kbd> |
| Neighboring cell | Arrow keys at the edge of the text |

## Mouse and touch

| Gesture | Does |
| --- | --- |
| <kbd>Space</kbd> + drag, middle or right drag | Move the canvas |
| <kbd>Ctrl</kbd> + scroll or pinch | Zoom |
| <kbd>Shift</kbd> + click | Add to selection |
| <kbd>Ctrl</kbd> + click | Select inside a group |
| <kbd>Alt</kbd> + click | Select the shape below |
| <kbd>Alt</kbd> + drag | Duplicate while dragging |
| Right-click or long-press | Open the context menu |
| Select a shape, then click or drag a dot beside it | Add or connect a shape ([quick connect](/knowledge-base/editor/shapes-and-quick-connect#quick-connect)) |
