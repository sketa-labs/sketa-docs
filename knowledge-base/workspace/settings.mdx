Workspace settings always apply to the current workspace: switch workspace from the workspace menu in the sidebar.

- **Settings → Workspace → General**: the workspace's name and image, leaving and deleting it.
- **Settings → Workspace → Preferences**: the policies (AI, public links). Admins only: members don't see this page.
- **Settings → Workspace → API keys**: API keys (your own; admins see every member's).

The plan and seats are on **Settings → Workspace → Billing** (see [Plans and billing](/knowledge-base/workspace/plans-and-billing)).

## General

- **Image**, shown in the workspace switcher: PNG, JPEG or WebP up to 1 MB.
- **Name**: how the workspace appears to its members.
- **Leave workspace**: members (not the owner) of a shared workspace can leave it and lose access to its boards.
- **Delete workspace**: admins type the workspace name to confirm. Boards, collections and members are removed, and an active Plus subscription is canceled right away. Your personal workspace can't be deleted.

Only admins change the name and image; members see them read-only.

## Preferences

Each switch saves as soon as you change it.

### AI

**AI**. When off, members cannot use AI features in this workspace (text to diagram, wireframe to code). See [AI](/knowledge-base/ai).

### Public links

**Public links**. When off, no new board links can be created and existing links stop opening (embeds and presentations too). They are kept, and work again when you turn it back on. See [Sharing and public links](/knowledge-base/boards/sharing-and-public-links).

Every change here is recorded in the [audit log](/knowledge-base/workspace/audit-log).
